# Chad's Pad: prototype

A clickable design prototype of the next version of Chad's Pad, a sticky-note worklist for a propane service department. It uses **demo data only** (fake names, 555 numbers), keeps everything in your browser's localStorage, and has no backend.

* App: `index.html`. The desk layout shows at 820px wide and up, the phone layout below that (`?view=phone` forces it).
* Scanner self-test on synthetic photos: `scanner-test.html`.
* OpenCV.js loads from docs.opencv.org. OCR is a Tesseract.js placeholder loaded from jsDelivr.
